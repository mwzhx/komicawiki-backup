使用教學

搜尋結果旁會出現數個超連結和按鈕。

clean html 按鈕可以複製清理過的 html， 可用於 pandoc 轉換 (pandoc -f html -t mediawiki) 。

copy wiki 按鈕可以以 MediaWiki 格式語法複製， 原理是使用 pandoc 直接在瀏覽器內轉換，手機使用時請注意流量 (50M 內) 。

底部的 html to wiki 按鈕，將 html 貼在底部的輸入框，就能把 html 轉換為 media wiki 語法。可以在 web archive 中找到要轉換的網頁，按右鍵另存新檔，再把檔案拖曳到輸入框中，按轉換即可。也能使用檔案輸入框的瀏覽功能選來選擇檔案。
